#### agent 译名统一：全书采用「Agent」

**决策依据**

校对中发现 agent 的译法在全书分成两派，且**同一章内还会前后切换**——像是同一章里两个译者各写了一半：

| 章节 | 前半 | 切换点 | 后半 |
|---|---|---|---|
| 第 1 章 | 1.1–1.2 用「智能体」 | 1.3 | 1.3–1.5 用 Agent |
| 第 6 章 | 章首–6.3 用 Agent | 6.4 | 6.4–练习 用「智能体」 |
| 第 7 章 | 7.1–7.2.1 用「智能体」 | 7.2.2 | 7.2.2–总结 用 Agent |
| 第 8 章 | 8.1–8.2 用 Agent | 8.3 | 8.3–总结 用「智能体」 |
| 第 9–11 章 | 全章「智能体」（占比 97%–99%） | — | — |

判定全书统一为 **「Agent」**：

1. **前 8 章是一个整体**——第 2–5 章的 Agent 占比已达 89%–100%，若第 1、6、7、8 章不跟随会分裂成两套术语；
2. **多个章标题本就是 Agent**——第 1、6、8 章，以及第 10 章的 `# 第 10 章 探索能够思考、监控和自适应的认知 Agent`（章标题用 Agent 而正文全用「智能体」，自相矛盾）；
3. **切换方向一致**——四章中"用 Agent 的那一半"分布在后半、前半、后半、前半，说明 Agent 更接近全书既有基线；
4. 反向统一（改为「智能体」）要推翻第 2–5 章已完成的 1137 处，代价大得多。

**保留「多智能体 / 单智能体」复合词**（全书 96 处）：第 4 章章标题、文件名与 README 目录条目都是「多智能体系统」，把正文的「多智能体」也改成「多 Agent」反而会与标题产生新的不一致。实现上用负向后顾 `(?<![多单])智能体` 精确匹配，只动独立作名词的用法。

**更正：`追踪` 与 `跟踪` 不是同义异体，而是有意区分**
